# Documentazione comune

Vale per tutte le versioni di Minecraft del repository. Codici, gruppi e regole dei documenti: [`AGENTS.md`](../AGENTS.md), sezione Documentazione.

| Codice | Documento | Contenuto | Tipo |
|---|---|---|---|
| **0001** | [progetto](0001-progetto.md) | Obiettivo, temi e principi del modpack | vivo |
| **0101** | [installazione](0101-installazione.md) | Istanze di Prism collegate al repository, comando di packwiz, mod da scaricare a mano, problemi comuni | vivo |
| **0201** | [sviluppo](0201-sviluppo.md) | Formato dei file del pack, script, workflow di GitHub, come si rilascia una versione | vivo |

La documentazione di ogni versione è in `<versione>/docs/`, la conoscenza sulle mod in `<versione>/mod-knowledge/`, i documenti di lavoro in `<versione>/lavoro/` (oggi `1.21.1/`). I risultati grezzi delle ricerche stanno in [`../ai-agents/stage/`](../ai-agents/README.md).
