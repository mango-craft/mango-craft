# ai-agents

Materiale di lavoro degli agenti AI che aiutano sul repository (regole in [`AGENTS.md`](../AGENTS.md)).

## `stage/`

I **risultati grezzi delle ricerche**, una cartella per ricerca: `<data>_<versione di Minecraft>-v<versione del pack>_<nome>/` (il segmento della versione manca quando la ricerca non riguarda una versione del pack, es. `2026-10-17_repository_organizzazione`). Dentro: report, tabelle, estratti di sorgenti, script usati per contare, nella lingua in cui sono nati.

Regole:
- si **aggiunge** soltanto: una cartella non si modifica né si cancella;
- **non è una fonte per lo stato attuale**: descrive un momento. Lo stato del pack è in `<versione>/docs/`, la conoscenza sulle mod in `<versione>/mod-knowledge/` e sui temi in `<versione>/theme-knowledge/`, il lavoro di ogni versione in `<versione>/lavoro/versioni/`;
- non ha un indice: il nome della cartella dice data, versione e argomento;
- anche il workflow **Esamina mod** scrive qui (`<data>_<versione>_esame-mod/`).
