# Deep research (25/10/2026): UnlimitedPeripheralWorks 1.21.1-1.9.2 and Turtlematic 1.21.1-1.4.10

Raw report of a research agent (sources read, nothing run). Spot-checked by the main session: UPW catch-all peripheral capability (`ForgePeripheralWorks.kt` L82, `ForgeCommonHooks.kt` L53-57), CC:T fallback to generic peripherals only when no capability (`PlatformHelperImpl.java` `PeripheralAccess.get`), AP Create/Beacon integration via `ComputerCraftAPI.registerGenericSource` (`addons/create/Integration.java`), Turtlematic blocklist tags (only ender_dragon, wither, warden), UPW issue #52.

Sources: UPW branch `1.21` (205d184, 17/09/2026 = 1.9.2); Turtlematic tag `v1.21.1-1.4.10` (jar from 17e92c2, 08/08) and branch `1.21` (e633a39, 11/08, unreleased fixes); CC: Tweaked 1.120.2 (common + NeoForge); AP 0.8.2a; Peripheralium branch 1.20.

## 1. UnlimitedPeripheralWorks (mod id `peripheralworks`), alpha, MIT
- Requirements: Kotlin for Forge [5,) (pack 5.12.0), NeoForge [21.1.217,21.2), CC:T ≥1.113.1. Config `config/peripheralworks.toml` (COMMON).
- Blocks (`peripheralworks:`): `peripheral_casing`; `universal_scanner` (blocks, entities, items, players; block form radius **24 free**, 0.5 s cooldown; turtle/pocket 8 free, up to 16 at fuel cost, 1 s — `SphereOperations.kt` L17-18); `ultimate_sensor` (`inspect(dimension|biome|weather|orientation|time|light|calendar|chunk)`); `item_pedestal`; `display_pedestal` (display only); `map_pedestal` (60 s cooldown); `remote_observer` (8 positions within 16 blocks, mixin on `ServerLevel.onBlockStateChange`); `peripheral_proxy` (up to 8 peripherals within 16 blocks wirelessly); `network_manager`; `flexible_reality_anchor` + `reality_forger` (decorative); `recipe_registry` (`getRaw`, search, `getEMI`); `informative_registry`; `flexible_statue` + `statue_workbench`; `entity_link` (Entity Card; `inspect`, scan around entity); `hologram_projector` (own text/item/block display entities only, limit 30, 16 blocks — `HologramProjectorPeripheral.kt` L125-138, 231-250); AE2-only blocks via conditioned built-in data pack.
- Items: `peripheralium_hub` (3 upgrades in one slot), `netherite_peripheralium_hub` (7), `ultimate_configurator`, `entity_card`, `analyzer` (no recipe), AE2-only tunnel.
- Turtle upgrades: hubs, universal_scanner, ultimate_sensor, hologram_projector, `natures_compass` (if Nature's Compass). Pocket: same + 4 Ars Nouveau casting upgrades (novice, apprentice, archmage spell books, caster tome), conditioned on `neoforge:mod_loaded`.
- Generic plugins: `inventory`/`item_storage`, `fluid_storage`, `energy_storage` (`*_extended` types); 1024 items per operation; `energyAlwaysTransferable=true`; turtles refuel from energy items, `energyToFuelRate`=250 FE per fuel point. Vanilla: beacon (`configure` consumes a payment item — `BeaconPlugin.kt` L77-118), jukebox, lectern (read/edit pages), note block, powered rail.
- Integrations with pack mods:
  - Ars Nouveau: any `ISourceTile` as `energy_storage` (unit "source"); Mob Jar `inspect`; pocket magic tome (`getSpells`, `select`, `getMana`, `cast()` with player's mana); config `[integrations.ars_nouveau]` (`enableCasterTomePocketUpgrade`, `enableSourceStorage`, `enableMobJarPlugin`, true). Built against Ars 5.12.1; pack 5.13.3: used classes/methods exist in 5.13.3 source; runtime not verified.
  - Occultism: storage controller and accessors as `item_storage` (+ `getMaxSlots`, `getUsedSlots`, `isBlacklisted`); Golden Sacrificial Bowl `isBusy`, `getCraftingInformation` (pentacle, ritual, conditions, time left); spirits via Entity Link. Built against 1.224.0 (pack 1.224.5).
  - Tom's Storage: Inventory Connector as `inventory` of the whole network (built against 2.3.2, pack 2.4.2, not verified).
  - Easy Villagers: trader/auto trader `hasVillager`, `inspect`; auto trader `get/setSelectedOffer`.
  - Create (built against 6.0.10): filters (`getFilterName`, `setFilterItem`, `clearFilterItem`), scroll values, linear actuator `inspect`, processing/sequenced recipes in the recipe registry; **contraption storage (items, fluids, trains included) through Entity Link + wrench**.
  - Nature's Compass: upgrade with `getBiomes`, `scheduleSearch(biome)`, `getState`, `getResult`.
  - EMI: drag ingredient/recipe onto computer screen → event; `getEMI(recipeId)`.
  - KubeJS: two block builder types (custom pedestals), inert without startup scripts.
- **Conflict**: UPW registers a CC peripheral capability on **every block** at LOWEST priority; CC:T uses generic peripherals only when no capability answers. AP 0.8.2a's Create (Basin, Blaze Burner, Fluid Tank, filters, scroll values) and Beacon integrations are generic sources → on blocks where UPW answers (any inventory/tank/energy, Create filter/scroll, beacon) UPW's peripheral replaces CC's generic one and **AP's methods disappear** (UPW typings: `create:basin` = extended inventory + filter + fluid, nothing from AP). Mods with own peripherals still win (AP blocks, Create's 19 native peripherals, Mekanism). Issue #52 (CC&A on 1.20.1 Fabric): maintainer's workaround = block tag `peripheralworks:ignore` (1.21: `data/peripheralworks/tags/block/ignore.json`). Mitigation: ignore tag in `matteo_tweaks` for `create:basin`, `create:blaze_burner`, `create:fluid_tank`.
- Mixins: TurtleBlockEntity (`peripheral()`), Lectern, LivingEntity.swing, ServerLevel.onBlockStateChange (targets exist in CC 1.120.2). No collisions with AP ids. Issue #107: UPW 1.9.1 + Turtlematic 1.4.10 + CC 1.120.0 start on NeoForge 21.1.244.
- Embedded libraries (1.21 sources not public): Broccolium 1.4.6 (platform library, no content), Tweakium 1.4.9 (peripheral framework, no content), Peripheralium 1.4.6 (items `peripheralium_dust`, `peripheralium_block`, `peripheralium_upgrade_template`; 1.20 recipes: blend = redstone + glowstone, smelted; 9 dust = block; template = 7 dust + bottle o' enchanting ×4).
- Recipes: casing = 4 iron + 4 coal + Peripheralium block; most blocks = casing + dust + vanilla part; hub = 2 diamonds, 2 emeralds, advanced wireless modem, 4 dust; netherite hub = smithing with netherite + template. No world generation, loot, villagers.
- Config bugs (`PeripheralWorksConfig.kt`): `enableGenericEnergyStorage` getter reads the fluid toggle (L25); `enableUltimateSensor` reads the scanner toggle (L59); `enableDisplayPedestal` reads the map pedestal toggle (L68); `enablePeripheralProxy` written under key `enableRemoteObserver` (L238/L244).
- Probable code bugs (not verified in game): hub `unequip` uses `filter` instead of `filterNot` (`PeripheraliumHubPeripheral.kt` L91) → possible duplication of the removed upgrade and loss of the others; upgrade limit off by one (L128); turtle hub accepts only items that are also pocket upgrades (L59).
- Issues: 19 open (#65 anchor dupe 1.20.1; #52; #93–96 statue rendering, fix on a branch; #112; #54). #107 (client NPE, 1.9.1) fixed by PR #108 (in 1.9.2). Releases 1.21.1 NeoForge: 1.8.0 (07/08), 1.8.1 (26/08), 1.9.0 (11/09), 1.9.1 (14/09), 1.9.2 (17/09), all alpha. Languages: English, Ukrainian.
- Verdict: 🟡 depends.

## 2. Turtlematic (mod id `turtlematic`), release, MIT
- Requirements: NeoForge [21.1.9,21.2), CC ≥1.116.1, Kotlin for Forge [5,). Config `config/turtlematic.toml` (COMMON). No integrations with other mods, no world generation, loot, villagers.
- 40 items: automata cores tier 1 `automata_core`; tier 2 `end`, `husbandry`, `protective`; tier 3 `netherite_*` and forged `brewing`, `smithing`, `enchanting`, `mason`, `mercantile`; tier 4 `starbound_*` (8); creative-only `creative_*` and `enormous_automata_core`; misc `soul_vial`, `filled_soul_vial`, `soul_scrapper`, `turtle_chatter`, `mimic_gadget`, `creative_chest` (creative), `chunk_vial`, `inspection_monocle`. 39 turtle upgrades, no pocket upgrades.
- Lua: all automata `look`, `use`, `swing`, `suck`, scan. End: `savePoint`, `deletePoint`, `points`, `warpToPoint`, `estimateWarpCost`, `distanceToPoint`, capture/release of blocks (blocklist only portals, end frame, bedrock); warp same dimension, cost √distance fuel. Husbandry: capture animals, `toggleAI`, `harvest`, `simulateGrow` (logs from a sapling without using it). Protective: capture, swing, AI toggle for any non-animal mob. Forged: smithing `smelt` (instant, 80 fuel/item), `smith`; enchanting `enchant`, `getPossibleEnchantments`, `refreshEnchantments` (free re-roll), `extractEnchantment`; brewing `brew`, `throwPotion`; mason `chisel`, `rotate`, `turnOver`, `changeShape`; mercantile `trade`, starbound `restock`. Misc: piston push/pull, bow `shoot`, lava bucket `void`, chunk vial (keeps chunk loaded), chatter, mimic, monocle `inspect`, soul scrapper `harvestSoul`, creative chest `generate`.
- Progression (`SoulHarvestRecipeRegistry.kt`): soul vial = 4 redstone + 2 emeralds + soul lantern, filled on 4 soul sand; core = filled vial + 2 diamonds + 2 iron + 4 sticks; soul scrapper turtle kills mobs without drops (`SoulHarvestRecipe.kt` L57): 3 endermen → End; pig+sheep+cow+chicken → Husbandry; iron golem → Protective; cleric/mason/librarian/toolsmith villager or wandering trader → forged (+ netherite ingot + Peripheralium template); netherite tier + netherite ingot; starbound + nether star; chunk vial = 6 gold + diamond + emerald + filled vial.
- Overlap with AP: AP already has Weak, Husbandry, End automata, overpowered versions, soul feeding, FE charging, warping (same code lineage); AP chunky ≈ chunk vial; AP Block Reader ≈ monocle. Same English names in EMI ("End automata core", "Husbandry automata core"). Extra: Protective, forged cores, tiers, piston, bow, lava bucket, chatter, mimic. English only.
- Balance risks: Protective capture removes the entity (`AutomataCapturePlugin.kt` L111), AI toggle from netherite tier (`ProtectiveAutomataCorePeripheral.kt` L51,61); works on **modded bosses** (Twilight Forest, Cataclysm, Mowzie's, Aether): `turtlematic:capture_blocklist` and `turtlematic:ai_control_blocklist` contain only ender_dragon, wither, warden. `extractEnchantment` moves all enchantments (curses included) onto a book for 10 fuel, 5% wipe chance (removed at starbound) (`EnchantingAutomataCorePeripheral.kt` L191-216); vanilla enchanting rules (ignores Apothic Enchanting, not verified); starbound `restock` resets offers of any merchant (`MercantileAutomataCorePeripheral.kt` L42-51); block capture with data like Carry On; starbound passive fuel 15%/tick +1.
- Bugs in released 1.4.10: `throwPotion` `coerceAtLeast(10)` (`BrewingAutomataCorePeripheral.kt` L139) with cost 10·e^power (`PowerOperation.kt` L16-21) → ~220,000 fuel minimum, unusable (fixed d2aeb0c 10/08, unreleased); warp points possibly not saved (write-back only in e633a39, 11/08); chunk vial release thread (d76d519, unreleased); config defaults outside their own ranges (`enchantmentWipeChance` 0.05 with min 0.1, `TurtlematicConfig.kt` L206; some cooldowns below 1000 minimum; creative values above maximums) → probable correction with log warning; power operation cost logged at INFO.
- Maintenance: Modrinth 1.21.1 NeoForge only 1.4.10 (08/08/2026); last commit 11/08; tag `v1.21.1-2.0.0-rc.1` exists.
- Verdict: 🟡, leaning towards waiting; if added, boss blocklists in the datapack.
